# 눈알이 빠지도록

작은 사무실에서 시작하는 서류 검토 타이쿤. 직원이 가져온 서류를 사내 규정집과 대조해
도장을 찍고, 번 돈으로 회사를 키웁니다.

**플레이:** [index.html](index.html) 을 브라우저로 열면 바로 시작합니다.
외부 의존성 없는 단일 HTML 파일이라 설치도 빌드도 필요 없습니다.

## 게임 방식

1. **직원이 서류를 가져옵니다** — 책상에서 일하던 직원이 완성된 서류를 결재함에 올려둡니다.
2. **규정집과 대조해 도장을 찍습니다** — 규정을 어긴 서류는 `반려`, 깨끗한 서류는 `승인`.
   반려 사유까지 정확히 고르면 수수료를 40% 더 받습니다.
3. **번 돈으로 회사를 키웁니다** — 책상·직원·사무실·컴퓨터·의자를 업그레이드하면
   사무실 그림이 실제로 바뀝니다.

오결재하면 수수료의 1.5배를 물고 신뢰도가 6 떨어집니다. 신뢰도가 0이 되거나
마감 정산에서 자금이 마이너스가 되면 폐업합니다.

## 검토 규정

하루에 하나씩, 총 10개가 순서대로 공개됩니다.

| # | 규정 | 공개 |
|---|------|------|
| 1 | 사번 형식 `EMP-0000` | 1일차 |
| 2 | 서명 누락 | 1일차 |
| 3 | 작성일 오류 | 1일차 |
| 4 | 부서 코드 불일치 | 2일차 |
| 5 | 결재 한도 초과 | 3일차 |
| 6 | 금액 계산 오류 | 4일차 |
| 7 | 사업자번호 형식 `000-00-00000` | 5일차 |
| 8 | 휴가 일수 불일치 | 6일차 |
| 9 | 거래 정지 업체 | 7일차 |
| 10 | 문서번호 중복 | 8일차 |

서류는 지출결의서·휴가신청서로 시작해 발주서(3일차), 계약검토서(6일차)가 열립니다.
어려운 서류일수록 수수료 배율이 높습니다.

## 단축키

| 키 | 동작 |
|---|---|
| `A` | 승인 |
| `D` | 반려 |
| `1`~`9` | 반려 사유 선택 |
| `G` | 규정집 |
| `S` | 회사 확장 |
| `P` | 일시정지 |

## 기술

- 의존성 없는 단일 HTML 파일 (바닐라 JS)
- 사무실은 **캔버스 2D 아이소메트릭 렌더러**로 그립니다 — 깊이 정렬, 천장 조명,
  걷는 애니메이션과 눈 깜빡임이 있는 캐릭터. 이미지 에셋을 쓰지 않고 전부 코드로 그립니다.
- 사운드는 **절차적 WebAudio** — 오디오 파일 없이 오실레이터와 필터로 효과음을 합성하고,
  배경음악은 직원 수에 따라 레이어가 쌓입니다.
- 진행 상황은 `localStorage`에 자동 저장됩니다.
- 라이트 / 다크(야근 모드) 테마 모두 지원합니다.
